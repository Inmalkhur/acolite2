# Админ закрытого Telegram-чата

Бот на сервере (aiogram + FastAPI) ведёт закрытый чат. Локальный веб-GUI настраивает тексты и правила, забирает логи и `.md`, а Ollama вызывается только когда в очереди есть NLP-задача.

## Что умеет бот

1. Фиксированное приветствие, сбор анкеты (ответ на приветствие или Ollama), кик через час без анкеты (отключаемо).
2. Логи с выгрузкой на локальную машину при подключении GUI и далее по интервалу (по умолчанию час, без поллинга).
3. Автокопирование постов из указанных каналов (бот должен быть админом канала).
4. Периодическое предупреждение наименее активному участнику.
5. Фильтр мата и запрещённых фраз с автомутом.
6. Сохранение длинных постов и серий сообщений в `.md`.
7. Кик по чёрному списку при появлении.
8. Ответы на «что такое …» и вопросы боту по файлам `data/glossary/*.md`.
9. «Запланировать … дата время» и напоминания за сутки, 3 часа и 1 час.
10. «Сделаю …» — список дел в `data/todos/`.

Ollama на локальной машине. Пока GUI офлайн, работают эвристики (ответ на приветствие, словарь мата, точный термин). Нейро-задачи копятся на сервере.

## Права в Telegram

- Создайте бота в BotFather, выключите **Group Privacy**.
- Добавьте бота в закрытый чат **администратором**: удаление сообщений, бан, ограничение участников.
- Для репостов из каналов добавьте бота админом этих каналов.
- Скопируйте `chat_id` после первого сообщения в чате (GUI подставит сам) или укажите вручную.

## Сервер (VPS)

```bash
cd server
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # BOT_TOKEN, LOCAL_SYNC_SECRET, PORT=43121
PYTHONPATH=. python3 -m app.main
```

Без `BOT_TOKEN` поднимается только API синка (удобно для GUI). С токеном — polling Telegram + тикер киков/напоминаний.

Пример systemd: `WorkingDirectory=/opt/chat-admin/server`, `Environment=PYTHONPATH=/opt/chat-admin/server`, `ExecStart=.../python -m app.main`.

Откройте порт **43121** (или поставьте nginx с TLS перед WebSocket `/ws`).

## Локальная машина

Каталог файлов — [`data/`](data/) рядом с репозиторием (анкеты, посты, глоссарий, todos, логи).

```bash
cd local
npm install
# DATA_DIR по умолчанию ../data
npm run dev -- -p 43122
```

Откройте http://127.0.0.1:43122 , укажите URL сервера и тот же `LOCAL_SYNC_SECRET`, нажмите «Подключить».

Ollama: `ollama serve` и модель из GUI (например `llama3.2`). GUI дергает `http://127.0.0.1:11434` только при NLP-задачах.

## Протокол синка

Локальный GUI открывает **один** WebSocket на `ws://сервер:43121/ws?secret=...`. Сервер шлёт snapshot, логи, `.md` и NLP-jobs. GUI не опрашивает API по таймеру: выгрузка логов — при коннекте и раз в N минут из настроек.
